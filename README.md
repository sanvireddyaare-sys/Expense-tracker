#  Expense Tracker (Python CLI)
The Expense Tracker is a command-line based application developed using Python to help users efficiently manage and analyze their daily expenses. It provides a simple, lightweight, and user-friendly solution for tracking financial activities without relying on complex tools or databases.

This application uses a CSV (Comma-Separated Values) file for persistent data storage, allowing users to easily store, retrieve, and manage expense records. Each entry includes key details such as date, category, amount, and description, ensuring structured and organized financial data.

The system offers a menu-driven interface where users can add new expenses, view all records, and filter data based on specific criteria such as month or category. These features enable users to identify spending patterns, monitor their financial habits, and make better budgeting decisions.

To enhance usability and data understanding, the application incorporates data visualization using the Matplotlib library. It allows users to generate:
- A pie chart for category-wise expense distribution  
- A bar chart for date-wise expense analysis  

These visualizations provide meaningful insights into spending trends and help users gain better control over their finances.

# Features
- Add and store expenses with date, category, amount, and description  
- View all expenses in a structured format  
- Filter expenses by month or category  
- Visualize data using pie and bar charts  
- Persistent storage using CSV files  

#  Tech Stack
- Python  
- CSV (File Handling)  
- Matplotlib (Data Visualization)  

# Use Case
This project is ideal for individuals who want a simple and effective way to track personal expenses, analyze spending behavior, and improve financial management.
