#  Expense Tracker (Python CLI)

##  Project Overview
The Expense Tracker is a command-line based application developed using Python to help users efficiently manage and analyze their daily expenses. It provides a simple, lightweight, and user-friendly solution for tracking financial activities without relying on complex tools or databases.

The application uses a CSV (Comma-Separated Values) file for persistent data storage, allowing users to easily store, retrieve, and manage expense records. Each record includes important details such as date, category, amount, and description, ensuring well-organized financial data.

---

##  Problem Statement
Managing personal expenses manually can be difficult and time-consuming. Many users lack a simple tool to track their daily spending and analyze their financial habits effectively.

This project aims to provide a straightforward and efficient solution for recording, organizing, and visualizing expenses.

---

##  Features
- Add and store expenses with date, category, amount, and description  
- View all expenses in a structured format  
- Filter expenses by month or category  
- Visualize expenses using:
  -  Pie chart (category-wise distribution)  
  -  Bar chart (date-wise analysis)  
- Persistent storage using CSV files  

---

##  Technology Stack
- Python  
- CSV (File Handling)  
- Matplotlib (Data Visualization)  

---

##  How It Works
The application runs in a menu-driven CLI environment where users can:
1. Add new expenses  
2. View all recorded expenses  
3. Filter expenses based on category or month  
4. Generate visual reports using charts  

---

##  Use Case
This project is ideal for individuals who want a simple and effective way to:
- Track personal expenses  
- Analyze spending behavior  
- Improve budgeting and financial planning
